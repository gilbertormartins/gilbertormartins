## 💼 Experiência em destaque

Um dos projetos de que mais me orgulho foi a criação de um dashboard em **Power BI**, desenvolvido praticamente do zero para substituir um processo mensal manual.

Nesse projeto atuei no levantamento de requisitos, tratamento e modelagem de dados, criação de indicadores em DAX, estruturação visual das informações e apresentação dos resultados para gestores.

O resultado foi a redução significativa do trabalho manual e a geração de novos insights para apoio à gestão.
